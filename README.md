# stb-control

Basic control of Roku and Android TV boxes

## Installation

```bash
sudo pipx ensurepath --global
sudo pipx install --global git+https://github.com/jpoet/stb-control.git
```
or
```
sudo pipx ensurepath --global
git clone https://github.com/jpoet/stb-control.git
cd stb-control
sudo pipx install --global .
```

## Usage

```
stb-control --device <hostname> --link <deeplink>
```
